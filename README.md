# Usage Metering & Billing Engine

Backend capstone project for the FlyRank AI internship.

## Status

Stage 0 — Project setup and architecture design.

Application functionality has not been implemented yet.

## Planned Technology

- Python
- FastAPI
- PostgreSQL
- Docker
- Docker Compose
- Stripe Test Mode
- Stripe CLI
- pytest

## Project Goal

Build a SaaS backend that:

- tracks API and AI-token usage
- prevents duplicate metering with idempotency keys
- enforces usage quotas
- calculates usage costs
- provides monthly usage information
- integrates with Stripe test mode
- synchronizes subscription plans through verified webhooks
- maintains tenant isolation
